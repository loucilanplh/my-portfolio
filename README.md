# Cloud security portfolio

A lightweight, responsive portfolio for a York University cybersecurity student pursuing cloud security analyst roles. It uses plain HTML, CSS, and JavaScript so it can be hosted as a static site, including on Amazon S3.

## Personalize before publishing

- Replace `Your Name` and `YN` in `index.html` with your name and initials.
- Replace `your.email@example.com` with your preferred email address.
- Add links to your GitHub, LinkedIn, résumé, and live project demo when you are ready.
- Review the project description and architecture details for accuracy against your deployed environment.
- The `pdf-jpg-converter.md` link currently points to the supplied project notes. Keep it public only if the notes contain no account IDs, bucket names, credentials, or other private details.

The project page describes the converter as deployed and end-to-end tested based on the owner's confirmation. The security review items are framed as areas for future assessment, not completed remediations.

## Preview locally

Open `index.html` in a browser, or start any static file server from this directory.
