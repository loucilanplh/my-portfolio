01SERVERLESS · AWS

PDF to JPG
converter

A serverless application that accepts PDF uploads and converts each page into a JPG. An event-driven pipeline connects API Gateway, Lambda, private S3 storage, and SQS. I deployed the system and verified the complete upload-to-image flow.

THE BUILD

API Gateway, Python Lambda, S3 event notifications, SQS, and a converter running in a private subnet with VPC endpoints.

THE SECURITY LENS

Private input and output storage, scoped Lambda permissions, short-lived presigned URLs, and clear trust boundaries between services.
